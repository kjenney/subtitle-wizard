Help & Quick Start

Getting Started (5 minutes)

  1. Open this app in Chrome, Firefox, Safari, or Edge
  2. Setup AWS Credentials - Click "AWS Credentials" below and enter your Access Key ID and Secret Key
  3. Upload a video - Drag & drop or click "Choose File" (MP4, WebM, OGG, MOV)
  4. Extract Audio - Click "Extract Audio" button
  5. Generate Subtitles - Click "Generate Subtitles" and wait for Polly
  6. Export SRT - Click "Export SRT" to download

1. AWS Credentials Setup

To use Amazon Polly for subtitle generation, you need AWS credentials:

  1. Sign in to AWS Console
  2. Go to IAM (Identity and Access Management)
  3. Create a new user or use an existing one
  4. Attach AmazonPollyReadOnlyAccess policy
  5. Copy your Access Key ID and Secret Access Key
Security Note: Your credentials are encrypted and stored only in your browser's local storage.
